# Scripts & Commands — nextjs-app

## Web

```bash
# Dev server
npm run dev

# Build
npm run build

# Type check
npm run type-check   # ou: tsc --noEmit

# Lint
npm run lint

# Testes unitários (Vitest)
npm run test

# Testes E2E (Playwright)
npm run test:e2e

# Codegen — gera *.generated.ts a partir do schema GraphQL
npm run codegen
```

Rodar `codegen` após qualquer alteração no schema GraphQL do backend.
