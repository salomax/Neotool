# Features

Feature specs live under domain folders:

- `spec/features/security/`
- `spec/features/transactions/`
- `spec/features/investment-portfolio/`
- `spec/features/market-data/`
- `spec/features/financial-planning/`

Each feature spec must follow `spec/templates/feature-spec-template.md` and cite code evidence.

Do not create feature specs by migrating `removed historical docs`. Create reverse specs from current implementation.
