```

Data Aggregation                  →  Envestnet Yodlee, Plaid, Akoya
Compliance                        →  RIA in a Box, ComplySci
```

> 67% of advisors now use integrated technology stacks, up from 48% in 2022.

### Platform Deep-Dives

#### Orion Advisor Solutions
- Scale: $5.8T AUA, 8M+ tech accounts, 17 of top 20 Barron's RIAs.
- Acquired Redtail CRM in 2021 — creating all-in-one suite.
- **Denali AI (2026 rollout):** Query Studio (natural language → data answers), AI Assistants (meeting prep, client digests), Reporting Assistant (automated narratives), Agentic Workflows (autonomous client flagging and opportunity detection).

#### SS&C Black Diamond
- Differentiator: Best-in-class client-facing portal — immersive data visualizations, branded reports, secure document sharing.
- Target: RIAs serving HNW/UHNW clients where client presentation is paramount.

#### Envestnet Tamarac
- $1B strategic platform roadmap (May 2025): "personalized advice at scale."
- UMA (Unified Managed Accounts) — combines multiple SMA strategies in one account.
- Harvest rebalancing + opportunistic harvesting (gains/loss alignment on reallocation).
- Advisor-traded sleeves for individual bonds, LPs, structured notes.

#### Addepar
- Positioned for family offices, private banks, institutional complexity.
- Unmatched for alternative assets (PE, hedge funds, real estate) + multi-currency.
- API-first open architecture.
- Pricing: enterprise (~$10k–$50k/year per firm).

#### Nitrogen (formerly Riskalyze)
- Risk Number technology (1–99 scale) — industry standard for quantified suitability.
- Portfolio proposals showing current risk score vs. proposed risk score.
- Compliance-grade audit trail for suitability conversations.

#### Vise
- $50B+ on platform; AI-individualized portfolios per client (not collective model portfolios).
- The only platform creating truly personalized portfolios at advisor scale.

#### Altruist "Hazel" (2026 launch)
- First agentic AI tool for tax planning in the advisory space.
- Autonomously executes tax-loss harvesting and rebalancing across multiple custodians.
- Shift from "recommends" to "executes."

### What Advisors Value Most (2025 Data — Kitces AdvisorTech Study)

1. Ease of use and speed of daily workflows
2. Quality of client-facing reporting and portal
3. Depth of rebalancing and tax-loss harvesting automation
4. CRM integration quality
5. Performance attribution accuracy
6. Proposal generation speed
7. Compliance documentation automation

### Proposal Workflow — Best-in-Class Pattern

| Tool | Capability |
|---|---|
| Investipal | Statement scanning in 2 min (AI); full proposal in 10 min vs. industry 3 hours |
| VRGL | 5-pillar comparison: performance, risk, diversification, taxes, fees — white-labeled PDF/PPT |
| CapIntel | Interactive visual proposals with current vs. proposed comparison |
| Stratifi | AI proposals in minutes; Reg BI documentation auto-generated |
| Orion Proposals | Native within Orion ecosystem |

**Standard workflow:**
1. Import client's current holdings (AI statement scan or Open Finance)
2. Build proposed portfolio (model or custom)
3. Gap analysis: allocation, risk, return, fees, tax impact
4. Suitability validation
5. Generate branded proposal document
6. Deliver to client, track open/accept/reject
7. On acceptance: record compliance document, set as reference allocation

### Brazil-Exclusive Required Features

These features do not exist (or are irrelevant) in global platforms but are critical for Brazilian investors:

| Feature | Context |
|---|---|
| **B3 / Área do Investidor integration** | API replaced CEI in 2022 — official source for equities, FIIs, BDRs, ETFs custody data |
| **Come-cotas** | Semiannual taxation of fixed-income funds (May + November levy) — automated calculation expected |
| **IR renda variável** | Monthly DARF, BRL 20k/month exemption for stocks, average cost with corporate events |
| **Average cost tracking** | Required for IR on RV — includes splits, reverse splits, bonus shares, subscriptions |
| **Brazilian benchmarks** | CDI, IPCA+X%, Ibovespa, IFIX, IMA-B — key reference rates for local performance evaluation |
| **Domestic funds** | CVM-registered funds with come-cotas, D+X liquidity, distinct NAV calculation |
| **Tesouro Direto** | Treasury bonds with mark-to-market specific to SELIC/IPCA/Prefixado structures |
| **FIIs** | REIT-like structure with tax-exempt monthly dividends for qualifying individual investors |
| **BDRs** | Brazilian depositary receipts — foreign shares listed on B3; specific IR treatment |
| **CRIs / CRAs** | Real estate / agribusiness receivables — IR-exempt for individuals |
| **Debentures de Infraestrutura** | Also IR-exempt; require specific classification and tracking |
| **Crypto IR (2026)** | DeCripto system (Receita Federal from July 2026) — OECD CARF standard |
| **Offshore + Lei 14.754** | Tracking offshore assets and annual income provisioning under new offshore tax law |

### The Critical Gap: No Independent All-in-One Brazilian Advisory Stack

In the US, advisors freely choose Orion, Black Diamond, Redtail, Nitrogen — custodian-agnostic tools.

In Brazil:
- Advisor uses broker platform (XP/BTG) **or** uses Smartbrain/Gorila for consolidation.
- **No integrated CRM + suitability + proposal generation + compliance in a single independent product exists.**

This is the primary market opportunity for the investment portfolio module in the advisory segment.

## 6. Regulatory Framework (Brazil)

### Open Finance

- Brazil has one of the most complete Open Finance systems globally.
- Phase 4 (current) includes insurance, pension, and **Open Investment**.
- 100M+ clients connected (2025).
- **Investment portability** regulated by CVM Resolutions 210 and 229 (2024) — effective January 2026.
- **ANBIMA suitability portability via Open Finance API** — planned for 2026 — single suitability profile valid across all institutions (eliminates repetition at each broker).

### Key Regulations

| Regulation | Scope | Impact |
|---|---|---|
| CVM Resolution 178 (AAI) | Advisory | Registration, conduct, audit trail |
| CVM Instrução 539 / CVM 50 | Advisory | Suitability assessment before any recommendation |
| ANBIMA Código de Distribuição | Advisory | Product distribution governance, client classification |
| PLD/AML | Advisory | KYC documents, suspicious activity |
| Open Finance Phase 4 | Both | Investment data sharing APIs |
| CVM Res. 210 / 229 | Both | Digital asset portability between custodians |
| B3 Área do Investidor APIs | Both | Official custody data source |
| Lei 14.754/2023 (Offshore) | Retail (advanced) | Annual income provisioning for offshore assets |
| DeCripto / OECD CARF (Jul 2026) | Retail (crypto) | Crypto reporting; monthly exchange reporting to Receita Federal |
| LGPD | Both | Personal data minimization, consent, export/delete |

### Global Trends

| Trend | Description |
|---|---|

| **Alternative Asset Tokenization** | Value of tokenized private assets in institutional funds grew 749% in 2024–2025 to USD 2.97B. Private credit tokenized grew 82% to USD 17.9B. JPMorgan Kinexys expanding to RE, infra, and private credit in 2026. |

| **Hybrid Advice** | Pure robo-advisors lost appeal — clients want human access during volatility. Hybrid models captured 60%+ of robo-advisory revenue. Betterment, Empower both evolved in this direction. |
